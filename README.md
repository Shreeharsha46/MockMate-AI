# MockMate — AI-Powered Technical Interview Agent

**An Intelligent, Adaptive, and Secure AI Interview Preparation System**

MockMate is a terminal-based AI interviewing platform designed to help students, aspiring software engineers, and technical professionals prepare for real-world technical interviews through personalized, interactive practice.

Developed using **Python, LangChain, LangGraph, and Deep Agents**, MockMate simulates a structured technical interview by asking questions individually, evaluating responses against validated scoring criteria, and providing actionable feedback.

Unlike conventional interview chatbots, MockMate incorporates **adaptive questioning, persistent session memory, weak-topic analysis, and context-aware interview management**, enabling a more personalized learning experience.

### Key Features

- **Intelligent Interview Simulation:** Conducts realistic, one-question-at-a-time technical interviews.
- **Structured AI Evaluation:** Assesses responses using validated scorecards and detailed feedback.
- **Adaptive Questioning:** Adjusts future questions based on candidate performance.
- **Weak-Topic Identification:** Tracks knowledge gaps and prioritizes improvement areas.
- **Persistent Session Memory:** Enables users to resume interviews and monitor progress across sessions.
- **Human-in-the-Loop Approval:** Provides Approve, Edit, and Reject controls for sensitive operations.
- **Secure Workspace Management:** Protects local files against unauthorized access and path traversal.
- **Context Management:** Maintains relevant interview context through conversation trimming and summarization.
- **Performance Reports:** Generates human-readable Markdown interview records.
- **Cost-Free Local AI:** Supports Ollama for local model execution without requiring paid APIs.

### Technology Stack

Python 3.12+ | LangChain | LangGraph | Deep Agents | Pydantic | SQLite | Ollama | uv | Pytest | Ruff

### Project Objective

To develop an accessible, reliable, and intelligent AI-powered interview preparation system that delivers structured assessment, personalized feedback, adaptive learning, and secure agent-based workflows.
